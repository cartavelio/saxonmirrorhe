The package com.saxonica.extfn contains implementations of extension functions in the Saxon namespace.

It also contains the class {@link com.saxonica.extfn.VendorFunctionSetPE} which acts as a factory class for generating instances of these extension functions

These extension are implemented using a variety of mechanisms. Some are implemented in the same way as system function. Some use the "integrated extension function" mechanism introduced in Saxon 9.2. A few still use the reflection mechanism, these are in class {@link com.saxonica.extfn.Extensions}.
