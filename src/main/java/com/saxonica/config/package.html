This package contains classes supporting configuration of Saxon-PE and Saxon-EE.

The two classes {@link com.saxonica.config.ProfessionalConfiguration} and {@link com.saxonica.config.EnterpriseConfiguration} contain methods for setting configuring properties; they also serve as factory classes used whenever there is a need for Saxon-PE or Saxon-EE to behave differently from Saxon-HE.

The classes {@link com.saxonica.config.ProfessionalTransformerFactory} and {@link com.saxonica.config.EnterpriseTransformerFactory} perform the same function at the JAXP level.

The {@link net.sf.saxon.trans.ConfigurationReader} is an internal class used to read an XML configuration file to create a corresponding Configuration object.
