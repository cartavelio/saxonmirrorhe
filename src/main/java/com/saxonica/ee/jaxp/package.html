This package contains the Saxon implementation of the JAXP schema validation API.

These classes allow a schema to be loaded and compiled and to be used for validating instance documents, typically validating the document emitted as a stream of events by a (non-validatin) SAX parser. The {@link com.saxonica.ee.jaxp.TypedContentHandler} gives access to the resulting type information.

This is not a mainstream interface for Saxon; it is provided only for JAXP compatibility. Most applications performing document validation will prefer to use the {@link net.sf.saxon.s9api} interface.
