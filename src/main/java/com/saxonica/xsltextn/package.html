This package contains classes used at compile time to support extensions to XSLT beyond 2.0: both facilities in the working draft of XSLT 3.0, and extensions specific to Saxon.

These classes are generally implementations of {@link net.sf.saxon.style.StyleElement}, representing elements on the stylesheet tree. They are instantiated using the factory class {@link com.saxonica.xsltextn.StyleNodeFactoryPE} or {@link com.saxonica.xsltextn.SaxonElementFactoryEE} as appropriate.
