XQJ
===

This directory contains various resources associated with the XQJ specification.

doc - the Javadoc for the XQJ API specification

ri - the reference implementation of the API

tck - the conformance test suite, a set of JUnit tests

XQJ_Spec_Final_Release_2009-03.pdf -- the definitive specification of XQJ.
