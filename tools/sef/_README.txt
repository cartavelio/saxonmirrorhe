SEF
===

Utility code associated with SEF files, status unknown.

sef-to-json.xsl is a stylesheet for converting SEF files from XML format to JSON format. This process is now integrated
in the product.

sef.xsd was an attempt at producing a schema for SEF files (in their XML format). It is almost certainly out of date, 
but could usefully be revived.

alphacodes.odt is a specification of the alphacodes used to represent Sequence Type information
in SEF files. It is probably not completely up to date.
